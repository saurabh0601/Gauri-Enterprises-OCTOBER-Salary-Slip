# Gauri Enterprises - Surlon India Limited | Salary Slip Portal

Professional GitHub Pages version.

## Files
- `index.html` — website
- `css/style.css` — professional styling
- `js/script.js` — Employee ID search
- `salary-slips/` — put employee files here

## Naming
Use the Employee ID as the filename:
- `GE0001.pdf`
- `GE0002.pdf`
- `GE00143.pdf`

JPG files are also supported:
- `GE0001.jpg`

## GitHub Pages
1. Create a GitHub repository.
2. Upload everything in this folder.
3. Add salary slips to `salary-slips/`.
4. Open repository Settings → Pages.
5. Select the main branch and root folder.
6. Save and open the generated Pages URL.

## Privacy
If the repository is public, salary slip files are publicly accessible by direct URL and the Employee ID search is not authentication. For real employee salary information, use a private/authenticated storage system.
